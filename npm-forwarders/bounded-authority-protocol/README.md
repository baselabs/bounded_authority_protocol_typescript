# bounded-authority-protocol

Use [`@bounded-authority-protocol/verifier`](https://www.npmjs.com/package/@bounded-authority-protocol/verifier) directly:

```bash
npm install @bounded-authority-protocol/verifier
```

This package only re-exports `@bounded-authority-protocol/verifier`, so that this name leads to the same project. It adds no code of its own.

It accepts any newer version of `@bounded-authority-protocol/verifier`. If you need stability, depend on the scoped package and
commit a lockfile. This package is published by hand and carries no provenance attestation; the scoped package
is where releases and attestations live.
